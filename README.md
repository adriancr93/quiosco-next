# Next.js

The React Framework for the Web

## What is Next.js?

Next.js is a React framework for building full-stack websites and applications. You can use React components to build your UI, and Next.js for additional features and optimizations.

Next.js automatically configures and compiles your application, so you can focus on building your app instead of dealing with configuration.

Its main feature is that it runs React on the server.

## Key Features

- Rendering
- Optimizations
- TypeScript
- Routing
- Data Fetching

## Next.js Routers: App and Pages Router

Since version 13, Next.js has two routers: the **App Router** and the **Pages Router**. For new projects, the App Router is recommended. The Vercel team has stated that they don't plan to remove the Pages Router, but all new Next.js features are added to the App Router.

The code between the App Router and the Pages Router is quite different, especially when it comes to file naming conventions and data fetching.
